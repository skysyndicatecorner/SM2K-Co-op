# SM2K Co-op

Любительский кооперативный мод для **Spider-Man (2000)**, порт на PC 2001 года (`SpideyPC.exe` v1.3).
Всю кампанию можно пройти вдвоём:

- **на одном компьютере** — разделённый экран, второй игрок на клавиатуре или геймпаде;
- **на двух компьютерах** — по локальной сети или через виртуальную сеть вроде Radmin VPN.

[English](README.md) · [Скачать](../../releases/latest) · [Изменения](CHANGELOG.md) · [План](docs/ROADMAP.md)

> Состояние: **v0.12, играбельная бета.** Игра вдвоём на одном ПК проверена автором в игре.
> Сетевой режим (этап 1) новый и пока тестируется. Возможны шероховатости, присылайте логи.

> сборку в игре. Подробнее: [AI_DISCLOSURE.md](AI_DISCLOSURE.md).

## Что умеет

| Режим | Состояние | Что есть |
|---|---|---|
| Разделённый экран (1 ПК) | играбельно | Второй Человек-паук. Своя камера и свой HUD в стиле игры. Своё здоровье и паутина, сохраняются между уровнями. Клавиатура или геймпад XInput. Враги нападают на обоих. Упавший второй игрок ждёт помощи: первый подходит и удерживает клавишу, чтобы его поднять. |
| LAN / Radmin VPN (2 ПК) | тест | Каждый играет на своём ПК и видит напарника с анимациями. Общие смерти врагов, триггер-зоны и смена уровня (конец, рестарт, провал миссии). |
| PvP | в планах | Арены из испытаний и сюжетных уровней без скриптов. Каждый сам за себя, команды, захват флага. |

Все настройки — в меню мода: нажмите **F6** в уровне.

## Установка

Нужна своя копия Spider-Man (2000) для PC, обновлённая до **v1.3**.
На других версиях мод проверяет exe и не включается. Файлов игры в моде нет.

1. Скачайте `sm2k-coop-<версия>-win32.zip` в разделе [Releases](../../releases/latest).
2. Скопируйте `dinput8.dll` (и при желании `coop.ini`) в папку игры, рядом с `SpideyPC.exe`.
3. Запустите игру и загрузите уровень. **F6** открывает меню мода.

Чтобы удалить мод, удалите `dinput8.dll`. Мод создаёт рядом с игрой только `coop.ini`, `coop_log.txt` и
`coop_log_prev.txt`.

### Управление (один ПК)

| Игрок | Клавиши |
|---|---|
| Игрок 1 | обычное управление игры |
| Игрок 2, клавиатура | W A S D — движение, K — прыжок, J — удар рукой, L — удар ногой, I — паутина, U / P / O — доп. действия, H — Enter |
| Игрок 2, геймпад | стик или крестовина, A — прыжок, B — удар ногой, X — удар рукой, Y — паутина, LB / RB / RT — доп. действия, START — Enter |
| Оба | F6 — меню, F9 / F11 — добавить / убрать игрока 2, F10 — перенести игрока 2 к первому, F8 — разделение экрана, F7 — раскладка, удерживать Num0 рядом с упавшим игроком 2 — поднять его |

### Игра по сети

1. **Хост:** F6, пункт `LAN CO-OP` — `HOST`.
   Узнайте свой IP: в Radmin VPN он вида `26.x.x.x`, в домашней сети — `192.168.x.x` (команда `ipconfig`).
2. **Друг:** F6, пункт `HOST IP`, Enter, наберите IP, Enter. Затем `LAN CO-OP` — `JOIN`.
3. В строке состояния меню должно появиться `OK: <НИК>`.
   Если вы на разных уровнях, друг выбирает `GO TO PARTNER`.

Если брандмауэр Windows спросит про `SpideyPC.exe`, разрешите доступ.
Если окна не было, выполните в командной строке от администратора:
`netsh advfirewall firewall add rule name="SM2K Co-op" dir=in action=allow protocol=UDP localport=27016`.

Ник задаётся в `coop.ini`, раздел `[lan]`, строка `nick=`.
Допустимы латинские заглавные буквы и цифры, до 15 символов.
Все ключи с пояснениями есть в [config/coop.ini.example](config/coop.ini.example).

## Сборка из исходников

Мод — один файл на C (`src/dinput8.c`), из него собирается 32-битная `dinput8.dll`.

| Чем собирать | Команда |
|---|---|
| Visual Studio (окно «x86 Native Tools Command Prompt») | `build.bat` |
| MSYS2 MINGW32 или Linux с `gcc-mingw-w64-i686` | `make` |
| Linux с clang и lld, без MinGW | `scripts/build-linux-clang.sh` (воспроизводимая сборка, ею собираются релизы) |

Релизные DLL собирает GitHub Actions из исходников с тегом версии.
Вы можете собрать DLL сами и сравнить SHA-256 (см. [SECURITY.md](SECURITY.md)).

## Как это устроено (коротко)

`dinput8.dll` — прокси-библиотека. Игра загружает её сама.
Мод передаёт вызов `DirectInput8Create` настоящей системной DLL и подменяет в памяти несколько вызовов в коде игры.

- **Второй игрок** — второй экземпляр игрового объекта игрока со своим контекстом камеры.
- **Разделённый экран:** кадр рисуется дважды, в две половины.
- **Сеть:** напарник — объект игрока, которым управляют данные из сети.

Подробно: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
