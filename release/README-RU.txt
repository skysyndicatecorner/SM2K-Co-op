SM2K Co-op — кооператив для Spider-Man (2000, PC)
==================================================

Неофициальный фанатский мод. Нужна своя копия игры версии 1.3.
Сделан с помощью ИИ (Claude от Anthropic), проверен человеком в игре.
Исходники и помощь: {{REPO_URL}}

УСТАНОВКА
  1. Скопируйте dinput8.dll в папку игры, рядом с SpideyPC.exe.
     Файл coop.ini можно скопировать туда же (в нём ник и настройки сети).
  2. Запустите игру, загрузите уровень и нажмите F6. Откроется меню мода.
  Удаление: удалите dinput8.dll.

ВДВОЁМ НА ОДНОМ ПК
  Второй игрок появляется сам в начале уровня.
  Клавиатура: W A S D — движение, K — прыжок, J — удар рукой, L — удар ногой, I — паутина,
  U / P / O — доп. действия, H — Enter. Геймпад: F6, пункт P2 GAMEPAD.
  F8 — разделение экрана, F7 — раскладка. Упавшего игрока 2 поднимает игрок 1:
  подойти и удерживать Num0.

ПО СЕТИ (LAN / Radmin VPN)
  Хост:  F6, пункт LAN CO-OP — HOST. Сообщите другу свой IP (Radmin: 26.x.x.x).
  Друг:  F6, пункт HOST IP, Enter, IP, Enter. Затем LAN CO-OP — JOIN.
  В строке состояния должно быть "OK: НИК". На разных уровнях друг выбирает GO TO PARTNER.
  Брандмауэр: разрешите SpideyPC.exe или выполните от администратора
    netsh advfirewall firewall add rule name="SM2K Co-op" dir=in action=allow protocol=UDP localport=27016

ЕСЛИ АНТИВИРУС РУГАЕТСЯ
  DLL-прокси, меняющие код игры в памяти, иногда принимают за вирус. Сверьте хеш:
    certutil -hashfile dinput8.dll SHA256
  Он должен совпадать с SHA256SUMS.txt. Затем отправьте файл как ложное срабатывание:
  https://www.microsoft.com/wdsi/filesubmission

ЕСЛИ ЧТО-ТО НЕ ТАК
  Рядом с игрой лежит coop_log.txt. Приложите его к сообщению об ошибке на GitHub
  (для сетевого режима — с обоих компьютеров).
