# Чем могут заблокировать мод и что с этим делать

Ниже перечислено всё, что может помешать проекту или игрокам: правообладатель, GitHub, антивирус, Windows,
сама игра и сеть. Для каждого случая указано, насколько это вероятно и как этого избежать или законно решить.

*Это не юридическая консультация.*

## Сводка

| Сценарий | Вероятность | Последствия | Главная защита |
|---|---|---|---|
| Жалоба правообладателя (DMCA) на GitHub | низкая | репозиторий скрыт | не хранить файлы игры, декомпиляцию, кряки и арт |
| Антивирус считает DLL вирусом | **высокая** | файл удалён у игрока | сборка в CI из открытого кода, хеши, жалоба на ложное срабатывание |
| SmartScreen / «файл скачивается редко» | средняя | предупреждение при скачивании | инструкция в README, со временем репутация растёт |
| Другая версия игры | средняя | мод не включается | проверка exe, требование v1.3 |
| Будущая Windows не загрузит прокси-DLL | низкая | мод не грузится | запасной способ загрузки (в планах) |
| Брандмауэр, провайдер, Radmin | средняя | нет связи по сети | правило брандмауэра, альтернативные VPN |
| Ограничение доступа к GitHub из страны | низкая, но возможна | нельзя скачать | зеркало кода на другой площадке |
| Ограничение аккаунта GitHub | низкая | репозиторий недоступен | копия на зеркале и локальная копия |

## 1. Жалоба правообладателя (DMCA takedown)

**Кто может пожаловаться:** правообладатели персонажа и игры.
По прецедентам удаляют в основном проекты, которые:
- раздают файлы игры или её исходный код (в том числе декомпилированный);
- снимают защиту от копирования (кряки, no-CD);
- используют логотипы и арт;
- зарабатывают на чужом бренде.

Обычные моды, которые требуют свою копию игры, трогают редко.

**Что сделано, чтобы повода не было:**
- в репозитории и релизе нет ни одного файла игры;
- нет декомпиляции и дизассемблера: в `.gitignore` запрещены `*.exe`, `*.pkr`, `SpideyPC*.c`, `*disasm*` и т. п.;
- мод не трогает защиту от копирования, и PR с no-CD будут отклоняться (это записано в CONTRIBUTING и LEGAL);
- название проекта SM2K Co-op не использует товарный знак как бренд. На сайте нет логотипов и изображений
  персонажа, только типографика;
- проект бесплатный, без донатов под брендом игры.

**Что делать, если жалоба всё же пришла:**
1. GitHub пришлёт уведомление и обычно даёт время исправить конкретный файл.
2. Если жалоба справедлива (например, кто-то закоммитил файл игры), удалите файл и вычистите его из истории
   (`git filter-repo`), затем ответьте GitHub.
3. Если жалоба ошибочна, по процедуре DMCA можно подать встречное уведомление (counter-notice).
   Это юридический документ, перед подачей лучше проконсультироваться.
4. Перезаливать то же самое содержимое в обход обоснованной жалобы нельзя: это продолжение нарушения, и
   так можно потерять аккаунт.
5. Зеркала (раздел 7) нужны на случай технических проблем и ошибочных блокировок, а не для обхода справедливых жалоб.

## 2. Антивирусы: самый вероятный сценарий

**Почему срабатывают:** мод делает то же, что и вредоносные программы, только с игрой:
- подменяет системную `dinput8.dll` (DLL-прокси);
- меняет код процесса в памяти (`VirtualProtect` и запись в код);
- открывает сетевой сокет (UDP).

Эвристики Windows Defender и других антивирусов могут назвать DLL «трояном» (Wacatac, Generic и т. п.).
Особенно часто это бывает с неподписанными DLL, которые недавно появились в сети.

**Что уже сделано:**
- DLL собирается **GitHub Actions из открытого кода**, у релиза есть подтверждение происхождения
  (build provenance attestation) и SHA-256;
- сборка **воспроизводимая**: `scripts/build-linux-clang.sh` даёт байт-в-байт тот же файл,
  каждый может проверить, что DLL собрана из этого кода;
- DLL не упакована (никакого UPX) и не обфусцирована, все импорты видны;
- мод ничего не скачивает и не запускает, а сеть открывает только по выбору игрока в меню.

**Что делать при срабатывании:**
1. Проверить хеш: `certutil -hashfile dinput8.dll SHA256` и сравнить с `SHA256SUMS.txt` в релизе.
2. Отправить файл как ложное срабатывание:
   - Microsoft: https://www.microsoft.com/wdsi/filesubmission («Software developer» → «Incorrectly detected»);
   - у других антивирусов есть аналогичные формы.
3. Загрузить релиз на VirusTotal и дать ссылку в описании релиза, чтобы игроки видели картину честно.
4. В будущем можно подписывать DLL: для открытых проектов бывает бесплатная подпись (например, программа SignPath
   Foundation для open source). Подписанные файлы ловят реже.
5. Игрокам: добавлять папку игры в исключения можно только после сверки хеша.
   Не советуйте отключать антивирус целиком.

## 3. SmartScreen и браузеры

При скачивании редкого архива Chrome и Edge могут предупредить, что файл скачивают редко.
Это не блокировка: файл можно сохранить. Со временем, по мере скачиваний, репутация файла растёт.
В README есть пояснение.

## 4. Версия игры

Мод проверяет сигнатуры кода `SpideyPC.exe` v1.3. На другой версии он пишет в лог `SIGNATURE MISMATCH` и не
трогает игру. Это защита от вылетов, а не блокировка. Игроку нужна версия 1.3.
Поддержать другие версии можно, если кто-то найдёт для них адреса: см. CONTRIBUTING.

## 5. Windows

`dinput8.dll` не входит в список KnownDLLs, поэтому Windows загружает её из папки игры первой.
Так работают тысячи модов, и сейчас поводов для беспокойства нет.

Если когда-нибудь это перестанет работать, есть запасные варианты загрузки:
- прокси для другой DLL, которую загружает игра (например, `winmm.dll` или `dsound.dll`, если игра их использует);
- ASI-загрузчик.

Это записано в план работ.

## 6. Сеть: брандмауэр, провайдер, VPN

- **Брандмауэр Windows** блокирует входящий UDP 27016 у хоста. Решение — разрешить доступ в окне Windows или
  выполнить `netsh` из README.
- **Radmin VPN** может быть недоступен или работать нестабильно. Мод работает с любой виртуальной сетью, которая
  даёт обоим ПК IP в одной сети: ZeroTier, Tailscale, Hamachi, свой WireGuard. Достаточно ввести IP хоста из этой сети.
- **Порт занят** — в меню меняется пункт `PORT`, у обоих должен быть одинаковым.
- Мод не использует серверы и не ходит в интернет сам. Заблокировать «сервер мода» нельзя: его нет.

## 7. Доступ к GitHub и зеркала

Доступ к GitHub из отдельных стран или для отдельных аккаунтов может ограничиваться: санкционные правила,
блокировки, ошибки модерации. Ситуация меняется, поэтому разумно заранее держать **зеркало собственного кода**:
- Codeberg (некоммерческий хостинг на Forgejo) или GitLab — можно настроить автоматическое зеркалирование;
- GitFlic — российская площадка, если важна доступность из России;
- локальная копия репозитория со всеми тегами (`git clone --mirror`).

Зеркало содержит тот же разрешённый к публикации код. Это обычная практика резервного копирования,
а не обход правовых ограничений.

## 8. Чего проект делать не будет

- Включать в репозиторий или релиз файлы игры, её exe, декомпиляцию.
- Снимать защиту от копирования и добавлять no-CD.
- Прятать код (обфускация, упаковщики), чтобы обмануть антивирусы. Это делает мод похожим на вирус и разрушает
  доверие.
- Скачивать что-либо из интернета без ведома игрока.
